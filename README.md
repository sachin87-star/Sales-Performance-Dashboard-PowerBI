# 📊 Retail Sales Performance Dashboard (Power BI)

## 🔍 Project Overview

This project focuses on analyzing retail sales data using Power BI to derive meaningful business insights.
The dashboard helps track sales performance, monitor targets, and identify key areas such as returns and category performance.

---

## 🎯 Objectives

* Analyze total sales and units sold
* Compare actual sales with targets
* Identify top-performing and low-performing salespersons
* Evaluate return impact on business
* Understand category-wise sales distribution

---

## 📈 Key Metrics

* 💰 Total Sales
* 📦 Units Sold
* 🔄 Return Orders
* 🎯 Target vs Achieved
* 📊 Achievement %
* 🏆 Top Salesperson

---

## 🛠 Tools & Technologies Used

* Power BI
* Microsoft Excel
* DAX (Data Analysis Expressions)

---

## ⚙️ Data Processing Steps

* Cleaned raw data (handled errors, removed invalid values)
* Converted data types (text to numeric where required)
* Created calculated measures using DAX
* Built relationships between Sales and Target tables

---

## 📊 Features of Dashboard

* Interactive slicers for salesperson filtering
* Sales vs Target comparison (line & bar chart)
* Category-wise sales analysis
* Return analysis with performance impact
* KPI cards for quick insights

---

## 💡 Key Insights

* Identified top-performing salesperson based on sales value
* Compared target vs achieved performance across all salespersons
* Analyzed return orders and their impact on total revenue
* Observed category contribution to total sales
